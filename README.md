# 🎂 Selamat Ulang Tahun, Sayang

Website ucapan ulang tahun romantis — satu halaman HTML, dari hero dengan countdown, surat cinta, harapan, timeline kenangan, sampai galeri foto berfilter.

## ✨ Fitur

- ⏳ Countdown mundur real-time menuju hari ulang tahun
- 💌 Section surat cinta bergaya polaroid
- 🌟 Section harapan & doa
- 🕰️ Timeline momen kenangan
- 🖼️ Galeri foto dengan filter kategori (Semua / Spesial / Cinta / Momen / Jalan-jalan)
- 📱 Responsive, bisa dibuka dari HP

## 🚀 Cara Pakai

1. Clone repo ini
   ```bash
   git clone https://github.com/ssinuratxx-wq/birthday
   ```
2. Buka `index.html` langsung di browser, atau publish lewat GitHub Pages
3. Edit isi sesuai kebutuhan (lihat bagian **Kustomisasi** di bawah)

## 🛠️ Kustomisasi

| Yang diganti | Lokasi |
|---|---|
| Nama pasangan | Cari teks `Sayang` di seluruh file |
| Foto | Ganti `src` di setiap tag `<img>` dengan foto asli |
| Tanggal ulang tahun | Ubah `targetDate` di bagian `<script>` paling bawah |
| Isi surat | Section `.letter-card` |
| Warna tema | Variabel CSS di `:root` (`--rose`, `--cream`, dll) |

## 🧱 Dibangun dengan

- HTML5 + CSS3 murni (tanpa framework)
- Vanilla JavaScript (countdown & filter galeri)
- Google Fonts — Playfair Display & Poppins
